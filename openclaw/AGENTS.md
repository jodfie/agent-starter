# OpenClaw Workspace Instructions

This file governs the OpenClaw **workspace**, not the project's source policy.

## Project contract

When working in a project created from Agent Starter, locate and follow that repository's root `AGENTS.md` plus any applicable nested `AGENTS.md` files. Project policy wins for project work; this workspace file adds OpenClaw-specific operating context.

## Workspace privacy

Treat the workspace as private memory. Never copy secrets, credentials, raw private conversations, or sensitive user memory into a public project repository.

## Session continuity

Use OpenClaw's normal workspace/memory mechanisms for personal/session continuity. Use the project's `tasks/ACTIVE.md`, ADRs, plans, Git history, and `HANDOFF.md` for project continuity that should be shared with other coding agents.

## Tools

Record machine/environment-specific conventions here, such as available CLIs, host aliases, or safe local paths. Never put credentials here.

## Completion

For project work, use the verification and definition-of-done rules in the project's root `AGENTS.md`.
