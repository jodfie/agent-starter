# Claude Code Adapter

Read and follow `AGENTS.md` as the canonical repository contract before substantive work.

This file intentionally does **not** duplicate repository policy. Claude-specific guidance belongs here only when it cannot be expressed portably in `AGENTS.md`.

## Startup

1. Read `AGENTS.md`.
2. Follow its startup protocol and any nested `AGENTS.md` applicable to files you touch.
3. Read `MISSION.md` and `tasks/ACTIVE.md` for current intent.

## Plans and delegation

For non-trivial work, preserve useful plans under `docs/plans/` when they need to survive the current session. When parallel agents/subagents are available, follow the delegation rules in `AGENTS.md`; the primary agent remains responsible for integration and verification.

## Completion

Do not report a task complete merely because code was written. Apply the verification contract and definition of done from `AGENTS.md`.
